# ── Catatan GPU (PENTING) ───────────────────────────────────────
# - PyTorch: wheel di bawah pakai CUDA 12.8 (cu128). Ini WAJIB kalau GPU
#   kamu Blackwell / RTX 50-series (mis. RTX 5060/5070/5080/5090,
#   compute capability sm_120) — wheel CUDA lama (cu121/cu124) TIDAK
#   punya kernel sm_120 dan akan gagal dengan "CUDA error: no kernel
#   image is available for execution on the device", atau diam-diam
#   training jalan di CPU. Wheel cu128 tetap backward-compatible untuk
#   GPU NVIDIA generasi lama (Ampere/Ada/dst), jadi aman dipakai semua.
#   Cek dulu compute capability GPU kamu: `nvidia-smi --query-gpu=compute_cap --format=csv`
# - MediaPipe: GPU delegate resmi TIDAK didukung di Windows (CPU-only) —
#   lihat github.com/google-ai-edge/mediapipe/issues/5126. Ekstraksi
#   keypoint MediaPipe akan selalu jalan di CPU meskipun training model
#   pakai GPU. Ini normal, bukan bug — estimasi waktu di
#   FeatureExtraction Setup.md sudah memperhitungkan ini.
# ══════════════════════════════════════════════════════════════
